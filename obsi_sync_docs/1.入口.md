# 项目说明
用 wails3 + svelte5 实现一个桌面端app, 用于同步各个obsidian库的配置

### 项目架构
Go = 业务核心 / 同步引擎
Svelte = 操作面板 / 可视化界面
Wails = 两边通信桥

# AI需要维护的文件
以下文件的作用是让新窗口的大模型快速了解项目状态，

- `2.项目功能状态.md`
记录项目当前目标、已实现功能和暂未实现功能

- `3.Wails_WebView2_视口缩放问题.md`
记录 Windows 下 Wails 页面视口与 DPI 换算异常的排查结果和下一步

#### 按需加载
- `4.国际化设计.md`
记录暂不实施的国际化功能状态、历史设计、开发计划、验证记录和未来重新评估条件

- `6.备份系统设计.md`
